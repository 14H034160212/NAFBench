What it tests

The word "not" doesn't mean one thing. In law, regulation, and medicine, the intended meaning depends on the reading in force: open- vs closed-world, two- vs three-valued, credulous vs skeptical. NAF-Bench gives a model a small logic program and tells it which reading to use, then checks whether it applies that reading rather than its gut default. Every instance is generated and certified by solvers (SWI-Prolog, a well-founded solver, and clingo), so the answer key is ground truth, and the test set is regenerated with fresh seeds to stay contamination-free.

Each program is asked under four specified readings:

  • closed_world (SLDNF / negation-as-failure)
  • cred — credulous stable-model: true in at least one answer set
  • skept — skeptical stable-model: true in every answer set
  • wfs — the well-founded (three-valued) model

Answers are A (definitely yes), B (definitely no), or C (cannot be determined). The primary metric is JOINT accuracy: a program counts only if all four readings are correct — this strips the lucky/vacuous coincidences a per-prompt average would reward.

Subtasks (benchmark versions)

NAF-Bench is generated by one solver-certified pipeline; it has grown through versions. The guess-baseline is what a program-blind constant (best fixed answer per reading) scores — a subtask is only meaningful when models beat it, so this column is the honest test of a version's validity.

The Frontier column is the tell: on v2 even o4-mini (83.3%) scores below the 100% constant — a frontier model loses to a program-blind guess, so the subtask measures nothing. On hard_v3 o4-mini (54.5%) clearly clears the 19.2% baseline, so the subtask is real. That is why hard_v3 is the scored competition; v1/v2 are kept for provenance. (Open models track the same story: 5.8–12.5% on the paper's base set, and no better than the guess on v1/v2.)

hard_v3 is further split into three context-budget tiers — 8k-lite (77 progs) ⊂ 16k (88) ⊂ full (99) — differing only in how much reasoning length a solution needs; pick the tier your model's context can handle.
